# Repository root hygiene

The repository root is the VioMacro app root. Keep source, app configuration, and developer entry points here so commands run without a wrapper directory.

## Tracked root files

- src/, functions/, public/, tests/, docs/, and scripts/.
- README.md, AGENTS.md, and the CLAUDE.md pointer.
- Package, TypeScript, Vite, Firebase, ESLint, Tailwind, PostCSS, and Playwright configuration.
- Firebase rules, indexes, .firebaserc, and environment examples.

## Local files

Environment values and generated output remain ignored. Use _local/ for local Firebase exports, browser traces, and development material:

```text
_local/
  firebase/
    data/
    exports/
  live/
  qa/
    playwright-report/
    test-results/
  archive/
```

The emulator wrapper supports local exports under _local/firebase/exports/. Playwright writes reports and traces under _local/qa/. dist/, .firebase/, and node_modules/ stay at the app root when generated by their tools.

## References and retired files

- Keep design concepts under [docs/design/moodboard/](../design/moodboard/) and retained prototype references under [docs/design/prototype/](../design/prototype/).
- Keep QA proof and browser guides under [docs/qa/](../qa/), including the [durable QA ledger](../qa/qa-ledger.md).
- Keep local recoverable retirements under _codex-trash/YYYY-MM-DD/ with their original relative paths; do not commit this folder.
- Preserve original path spellings in dated evidence and exact historical commit allowlists. Current guidance follows [the folder structure](folder-structure.md).

## File safety

Tracked folder moves use git mv and are reviewed with imports, references, and relevant checks. Do not sweep ignored secrets, existing emulator exports, dependencies, or unrelated user changes into a tracked migration. Do not move Firebase config files independently of their relative rules, indexes, Functions, or Hosting targets. Do not relocate an existing emulator export unless the wrapper still resolves it. Run npm.cmd run check and the relevant browser suites after structural work.
